# 디자인 문서

데이로그의 시각 언어와 매체별 디자인 기준을 관리합니다.

## 상태 구분

| 상태 | 의미 |
| --- | --- |
| 공통 기준 | 여러 화면과 매체에서 계속 참고하는 원칙 문서 |
| 구현 완료 | 현재 코드에 반영되고 검수 결과가 기록된 문서 |
| 부분 구현 | 주요 내용은 반영됐지만 보류 또는 후속 변경 항목이 남은 문서 |
| 코드 반영·검수 전 | 현재 작업 코드에는 반영됐지만 최종 검수와 완료 기록이 남은 문서 |
| 기획 확정·구현 전 | 다음 구현 기준으로 확정됐지만 아직 코드에는 반영되지 않은 문서 |
| 이전 기록 | 과거에는 구현됐지만 현재 디자인에서는 대체된 문서 |
| 제작 전 | 디자인 또는 필요한 자료만 정의됐고 결과물은 아직 없는 문서 |
| 자료 수집 중 | 구현·제작에 필요한 원본 자료나 운영 결정을 모으는 문서 |
