# 데이로그 디자인 토큰

## 문서 목적

브랜드 디자인을 일관된 코드로 구현하기 위한 토큰 기준입니다. React·TypeScript 프로젝트의 CSS 기반 토큰으로 사용하며, CSS Modules·CSS-in-JS 등 실제 스타일 방식이 정해져도 같은 의미와 이름을 유지합니다.

## 컬러 토큰

```css
:root {
  --color-brand-navy: #172033;
  --color-brand-yellow: #f5b82e;
  --color-brand-ivory: #fff9ef;
  --color-brand-beige: #ede1cf;
  --color-brand-sage: #879a7b;
  --color-brand-charcoal: #252525;
  --color-brand-white: #ffffff;
  --color-canvas-soft-gray: #f6f7f5;
  --color-input-surface: #fffefb;
}
```

## 의미 기반 컬러 토큰

컴포넌트에서는 가능하면 원색 이름보다 의미 기반 토큰을 사용합니다.

```css
:root {
  --color-background: var(--color-canvas-soft-gray);
  --color-surface-warm: var(--color-brand-ivory);
  --color-surface: var(--color-brand-white);
  --color-surface-muted: var(--color-brand-beige);
  --color-surface-dark: var(--color-brand-navy);

  --color-text: var(--color-brand-charcoal);
  --color-text-strong: var(--color-brand-navy);
  --color-text-on-dark: var(--color-brand-white);

  --color-action: var(--color-brand-yellow);
  --color-action-text: var(--color-brand-navy);
  --color-progress-complete: var(--color-brand-navy);
  --color-progress-current: var(--color-brand-yellow);
  --color-growth: var(--color-brand-sage);
  --color-growth-text: var(--color-brand-charcoal);

  --color-border: color-mix(in srgb, var(--color-brand-navy) 18%, transparent);
  --color-focus: var(--color-brand-navy);
}
```

브라우저 지원 범위를 고려해 `color-mix()`를 사용하지 않는 환경에서는 계산된 고정 색상으로 대체합니다.

## 컬러 조합 규칙

| 배경 | 기본 텍스트 | 강조 및 행동 |
| --- | --- | --- |
| Warm Ivory | Charcoal 또는 Deep Navy | Growth Yellow 하이라이트와 버튼 |
| Clean White | Charcoal 또는 Deep Navy | Deep Navy 링크와 Growth Yellow 버튼 |
| Soft Beige | Charcoal 또는 Deep Navy | Deep Navy 아이콘 |
| Deep Navy | Clean White 또는 Warm Ivory | Growth Yellow 버튼과 강조 |
| Sage Green | Charcoal 또는 Deep Navy | 색상 외 형태로 추가 강조 |

- Warm Ivory 위 Growth Yellow 글자는 사용하지 않습니다.
- Sage Green 위 Clean White 일반 텍스트는 사용하지 않습니다.
- Growth Yellow 버튼은 Deep Navy 텍스트를 사용합니다.
- 분홍색 형광펜과 포스트잇 전용 컬러는 현재 신청폼에서 사용하지 않습니다.
- Sage Green은 신청 완료 체크·완료 기하학 도형·완료 후 일정 안내 아이콘처럼 실제 완료 의미가 있는 화면에만 사용합니다.

공식 서체가 정해질 때까지 시스템 산세리프 스택을 사용합니다.

```css
  --font-size-caption: 0.875rem;

  --font-size-heading-2: clamp(1.875rem, 4vw, 2.25rem);
  --font-size-heading-1: clamp(2.25rem, 5vw, 3rem);
  --font-size-hero: clamp(2.375rem, 7vw, 4rem);

  --line-height-tight: 1.15;
  --line-height-heading: 1.25;
  --line-height-body: 1.7;

  --font-weight-regular: 400;
  --font-weight-medium: 500;
  --font-weight-semibold: 600;
  --font-weight-bold: 700;

```

## 간격 토큰

8px 단위를 중심으로 하고 4px을 세부 조정 단위로 사용합니다.

```css
:root {
  --space-1: 0.25rem;
  --space-2: 0.5rem;
  --space-3: 0.75rem;
  --space-4: 1rem;
  --space-5: 1.5rem;
  --space-6: 2rem;
  --space-7: 3rem;
  --space-8: 4rem;
  --space-9: 6rem;
  --space-10: 8rem;
}
```

- px 단위의 `padding`, `margin`, `gap`은 원칙적으로 4의 배수만 사용합니다.
- 권장 순서는 `4px`, `8px`, `12px`, `16px`, `20px`, `24px`, `32px`, `48px`입니다.
- 시각적 숨김을 위한 `-1px`, 테두리 두께, 아이콘·제본의 물리적 치수와 변형 값은 예외입니다.

## 레이아웃 토큰

```css
:root {
  --content-narrow: 42rem;
  --content-default: 72rem;
  --content-wide: 80rem;
  --page-gutter: clamp(1.25rem, 4vw, 3rem);
  --section-space: clamp(4.5rem, 10vw, 8rem);
}
```

### 반응형 보정 토큰

```css
:root {
  --control-height: 2.75rem;
  --touch-target-min: 2.75rem;
  --page-gutter: 1rem;
  --scene-min-height: 100dvh;
}

@media (width >= 37.5rem) {
  :root {
    --control-height: 3rem;
    --page-gutter: 1.5rem;
  }
}

@media (width >= 52.5rem) {
  :root {
    --control-height: 3.25rem;
    --page-gutter: 2rem;
  }
}

@media (width >= 80rem) {
  :root {
    --page-gutter: 2.5rem;
  }
}
```

`37.5rem`, `52.5rem`, `80rem`은 기본 글자 `16px` 기준으로 각각 약 `600px`, `840px`, `1280px`입니다. CSS 커스텀 속성은 미디어 쿼리 조건에 직접 사용할 수 없으므로 breakpoint는 스타일 레이어나 빌드 설정의 공통 상수로 별도 관리합니다.

## 신청폼 카드 프레임 (2026-09-08)

사용자 이미지 초안에 맞춰 신청폼에서는 아래 공통 프레임을 사용합니다. 브랜드 컬러는 기존 값을 유지합니다.

```css
:root {
  --app-frame-max-width: 440px;
  --app-frame-height: clamp(360px, calc(100dvh - 40px), 680px);
}
@media (width >= 600px) {
  :root { --app-frame-height: clamp(360px, calc(100dvh - 56px), 680px); }
}
```

후속 요청에 따라 바깥 프레임의 배경과 테두리는 투명하게, 모서리는 0, 그림자는 없음으로 적용합니다. 로고·진행 막대는 이 투명 컨테이너 안에서 페이지 바탕 위에 표시합니다. 상세 여백·내부 스크롤은 [중앙 패널 명세](../04-디자인/신청폼-중앙-패널-비율-일관화-기획.md)를 따릅니다.

## 모서리와 그림자

```css
:root {
  --radius-small: 0.5rem;
  --radius-medium: 0.875rem;
  --radius-large: 1.5rem;
  --radius-pill: 999px;

  --shadow-card: 0 12px 36px rgb(23 32 51 / 0.08);
  --shadow-floating: 0 18px 48px rgb(23 32 51 / 0.14);
}
```

- 정보 카드는 `--radius-medium` 또는 `--radius-large`를 사용합니다.
- 버튼을 모두 pill 형태로 만들지 않습니다. 브랜드가 지나치게 캐주얼해 보이지 않게 기본 버튼은 `--radius-medium`을 사용합니다.
- 그림자는 꼭 필요한 레이어 구분에만 사용합니다.

## 버튼 토큰

```css
:root {
  --button-height: 3rem;
  --button-padding-inline: 1.25rem;
  --button-gap: 0.5rem;
  --focus-ring-width: 3px;
  --focus-ring-offset: 3px;
}
```

### Primary 버튼

```css
.button-primary {
  min-height: var(--button-height);
  padding-inline: var(--button-padding-inline);
  color: var(--color-action-text);
  background: var(--color-action);
  border: 1px solid transparent;
  border-radius: var(--radius-medium);
  font-weight: var(--font-weight-bold);
}
```

### 포커스 상태

```css
:focus-visible {
  outline: var(--focus-ring-width) solid var(--color-focus);
  outline-offset: var(--focus-ring-offset);
}
```

Growth Yellow 배경의 버튼 자체에서는 포커스 링이 보이지 않을 수 있으므로 Deep Navy 외곽선 또는 이중 링으로 컴포넌트별 보완합니다.

## 모션 토큰

```css
:root {
  --duration-instant: 100ms;
  --duration-fast: 140ms;
  --duration-default: 220ms;
  --duration-slow: 420ms;
  --duration-scene: 700ms;
  --duration-scene-max: 900ms;
  --stagger-short: 60ms;
  --motion-distance-short: 0.75rem;
  --ease-standard: cubic-bezier(0.2, 0.8, 0.2, 1);
}
```

- 모션은 읽기 순서와 상태 변화를 돕는 수준으로 사용합니다.
- 각 모션은 시작·완료 상태, 트리거, 중단 처리와 정지 대체 상태를 같이 정의합니다.
- 등장 스태거의 누적 지연은 `600ms`를 넘지 않습니다.
- 애니메이션 속성은 `transform`과 `opacity`를 우선합니다.
- 인물이 크게 이동하거나 CTA가 반복해서 튀는 애니메이션은 사용하지 않습니다.
- `prefers-reduced-motion` 환경에서는 큰 이동, 회전, 패럴랙스와 반복을 제거하고 `100~180ms` 페이드 또는 즉시 완료 상태로 대체합니다.


## 구현 규칙

- 컴포넌트 내부에 HEX 값을 반복해서 직접 입력하지 않습니다.
- 색상 역할이 바뀌면 의미 기반 토큰 한 곳에서 수정할 수 있어야 합니다.
- 토큰 이름은 시각적 속성과 의미를 구분합니다.
- 디자인 시스템에 없는 임의의 네이비, 노랑, 베이지를 추가하지 않습니다.
- 새 토큰을 만들 때 기존 토큰으로 해결할 수 없는 이유를 확인합니다.
