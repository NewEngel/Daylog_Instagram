# 신청폼 변경 기록

## 2026-09-08

### 전체 선택형 답변 UI 통일

- 생활 질문 1~5와 신청 일정의 요일·시간 답변을 공통 `AnswerChoice`와 2열 그리드로 통일했습니다.
- 버튼 크기·간격·글자·모서리·선택 배경·테두리·체크를 통일하고, 습관은 같은 표시 위치에 순위를 유지했습니다.
- 질문별로 중복되어 있던 선택 카드·칩·습관 카드 스타일을 공통 스타일로 정리했습니다.
- 설명 줄바꿈, 기타 입력, 순위 취소 후 재정렬, 일정 상관없음 배타 선택과 오류 입력 포커스를 브라우저에서 확인했습니다. 실제 신청은 제출하지 않았습니다.
- 빌드·린트·데이터 계약 테스트 8개 통과. 320px·390px 모바일에서 2열과 가로 넘침 없음을 확인했습니다.

### 3번 문항 답변 2열 배치

- `어떤 순간에 가장 힘이 빠지나요?`의 답변 8개를 같은 너비의 2열 × 4행으로 배치했습니다.
- 작은 화면에서는 긴 문구를 줄바꿈하며, 기타 입력은 답변 목록 아래 전체 너비로 유지합니다.

### 바깥 카드 제거 후 바탕에 직접 배치

- 사용자 후속 요청에 따라 공통 패널의 흰 배경·테두리·둥근 모서리·그림자를 제거했습니다.
- 로고·제목·진행 막대·버튼이 회백색 바탕 위에 표시됩니다. 컨테이너 치수와 내부 스크롤, 선택지·입력칸은 유지합니다.
- 진행 막대의 남은 구간은 바탕과 구분되도록 기존 테두리 토큰으로 조정했습니다.

### 이미지 초안 기반 UI 수정

- 인트로·질문·완료 화면에 중앙 로고, 흰 카드, 크림색 안내와 노란 CTA를 적용했습니다.
- 최대 440px 공통 카드 내부로 헤더를 옮기고 질문·신청 진행 막대를 단일 노란 막대로 바꿨습니다.
- 질문 제목을 가운데 정렬하고, 단일 선택 체크를 오른쪽으로 옮겼습니다. 선택 배경과 네이비 테두리, 키보드 포커스 표시를 유지했습니다.
- 인트로의 문자 아이콘을 선형 SVG로 교체하고, 완료에는 CSS 세이지색 기하학 도형·일정 안내를 추가했습니다. 접수번호와 복사 기능은 펼칠 수 있는 신청 내역에 유지했습니다.
- 실제 질문은 5개이므로 초안의 4개 표시는 적용하지 않았고, 기존 질문 의미·선택값·제출 스키마와 연동은 유지했습니다.
- UI 버전 `2026.09.4`. 빌드·린트·기존 테스트 20개 통과. 반응형 검수 결과는 [검수 결과](검수-결과.md)를 참고합니다.


## 2026-09-05

### UI 공간 활용과 전체 진행 안내 개선

- 습관 카드를 최소 높이 142px에서 80px로 줄이고 3열(360px 미만 2열)로 배치했습니다. 순위 선택·취소 및 접근성용 순위 안내를 유지했습니다.
- 이전 버튼을 44px 이상 터치 영역의 텍스트 버튼으로 바꿔 주 행동과 한 줄로 배치했습니다.
- 신청 기본 정보·일정의 중복 카드 제목·설명·테두리를 제거하고 개인정보 안내의 중복 헤더도 정리했습니다.
- 모든 화면에 `생활 질문 → 프로그램 안내 → 신청` 표시를 추가하고, 헤더에는 세부 진행 수를 유지했습니다. 새 진행 영역에 맞춰 패널 외부 예약 공간을 136/144/184px로 조정했습니다.
- 안내 화면에 실제 결과와 혼동하지 않도록 명시한 작은 행동 예시를 추가했습니다. 실제 사진은 자료 확보 전까지 보류합니다.
- 1280×720에서는 단일 선택 카드의 세로 여백을 추가로 줄여 첫 질문 4개가 스크롤 없이 보이도록 했습니다.
- UI 버전 `2026.09.3`. 빌드·린트·기존 테스트 20개 통과. 브라우저에서 390×844 전체 입력 흐름, 320×568 습관 스크롤, 1280×720 인트로·첫 질문, 820×1180 첫 질문을 확인했습니다. 실기기 키보드·실제 제출은 이번 검수 범위에 포함하지 않았습니다.
- 상세 기준은 [UX 단순화 기획의 후속 반영](../04-디자인/신청-폼-UX-단순화-2차-개편-기획.md#2026-09-05-ui-평가-후속-반영)을 참고합니다.


## 2026-09-04

### 선택 카드 장식 배지 제거

- 하루 리듬과 집중 조건 선택 카드 오른쪽의 노란 번호 배지(`06`, `12`, `01` 등)를 제거했습니다.
- 습관 선택 카드 왼쪽의 노란 영문 배지(`Z`, `M`, `E` 등)를 제거했습니다.
- 장식용 `marker` 데이터를 `ChoiceOption` 타입과 선택지 데이터에서 함께 제거했습니다.
- 실제 선택 여부를 알려주는 체크 원과 습관의 `1순위`, `2순위`, `3순위` 표시는 기능 정보이므로 유지했습니다.
- 선택 카드의 그리드 열과 습관 카드 상단 정렬을 조정해 배지가 사라진 자리에 불필요한 여백이 남지 않게 했습니다.
- `npm test`(20개), `npm run lint`, `npm run build`를 통과했고 브라우저에서 하루 리듬·집중 조건·습관 카드의 배지 제거와 선택 순위 표시를 확인했습니다.

### 전 챕터 중앙 패널 동일화 구현

- 중앙 패널 비율 일관화 기획을 개정한 [신청폼 전 챕터 중앙 패널 동일화 기획](../04-디자인/신청폼-중앙-패널-비율-일관화-기획.md)에 따라, "콘텐츠에 맞춰 늘어나는 최소 높이" 방식을 "같은 viewport에서는 모든 챕터가 완전히 동일한 고정 크기 + 내부 스크롤" 방식으로 바꿨습니다.
- `.app-panel`에 `min-height` 대신 `height: clamp(320px, 100dvh - 외부여백, 640px)`(모바일 112px·태블릿 120px·데스크톱 160px)과 `overflow: hidden`을 적용했습니다.
- 모든 화면에 `.chapter-scroll-area`(캡션·제목·본문·오류 메시지를 담는 내부 스크롤 영역)를 추가하고, 이전·다음·제출 버튼은 스크롤 영역 밖에서 항상 패널 하단에 고정되도록 구조를 바꿨습니다. 신청 3단계는 각 `<form>` 안에서 같은 구조를 재사용합니다.
- 데스크톱 전용 sticky 행동 영역과 짧은 화면의 `min-height: auto` 예외를 제거했습니다. 고정 높이 패널이 모든 화면에서 동일하게 동작하기 때문입니다.
- 챕터 전환 시 내부 스크롤을 맨 위로 초기화하고, 오류·기타 입력 포커스 시 `scrollIntoView`로 스크롤 영역 안에서 보이도록 했습니다.
- 브라우저에서 직접 측정: 1280×720에서 인트로~신청 1/3까지 560×560px, 375×812에서 335×640px로 모든 챕터가 동일했습니다. 습관 9개 카드, 기타 입력 펼침 상태에서도 패널 크기는 그대로였고 본문만 스크롤됐습니다.
- `npm test`(20개), `npm run lint`, `npm run build`를 통과했습니다. 200% 확대와 실제 모바일 키보드 상태는 자동화로 확인하지 못해 실기기 검수가 남아 있습니다.

### UX 단순화 2차 개편 구현

- 온도 페이지(힘이 나는 때/지치는 때)를 자유 텍스트 입력에서 선택형 버튼으로 바꾸고, 화면을 2개로 분리했습니다. 질문 총 단계가 4 → 5개로 늘었습니다. (2026-09-04 후속 요청으로 텍스트 직접 입력을 완전히 없애고 9개 버튼으로 전환한 뒤, 아침/오전·오후/저녁처럼 겹치는 단어를 정리해 새벽·아침·점심·저녁·밤·출퇴근길·매일 달라요 7개 버튼으로 최종 확정)
- 지속 페이지 질문을 `집중이 가장 잘되었던 때는?`으로 간소화하고, 5개 선택지의 설명 문장을 제거해 단답형 라벨만 남겼습니다.
- 습관 페이지 질문을 `지금 가장 변화되고 싶은 습관은?`으로 바꾸고, 9개 선택지의 설명 문장을 제거했습니다. 선택지 개수와 1~3순위 배지 방식은 그대로 유지했습니다.
- 신청 페이지를 기본 정보·가능한 일정·개인정보 동의 3단계로 나누고, 안내 페이지와 중복되던 `contact-memo-card`(📍1:1/⏱️60분/🔒3개월 삭제)를 제거했습니다.
- 질문 제목에 캡션 라벨과 핵심 단어 밑줄 강조를 추가하고 제목 글자 크기를 키웠습니다. 선택 카드 번호 배지를 Growth Yellow 배경 pill로 바꿨습니다.
- 온도 페이지 분리에도 불구하고 퍼널 이벤트는 두 번째 화면에서만 `energy_selected` 1회를 전송해 기존 9단계 퍼널·v3 데이터 계약을 그대로 유지했습니다.
- 안내 페이지 이미지 삽입은 실제 사진 자산이 없어 이번 개편에서 보류했습니다.
- 폼 UI 버전을 `2026.09.2`로 올렸습니다. `npm test`(19개), `npm run lint`, `npm run build`를 통과했고 데스크톱·모바일(375×812) 브라우저에서 전체 흐름을 확인했습니다.
- 상세 기획은 [신청폼 UX 단순화 2차 개편 기획](../04-디자인/신청-폼-UX-단순화-2차-개편-기획.md) 참고.

### 중앙 패널 비율 일관화 구현

- 인트로부터 완료까지 모든 화면의 `.app-panel` 최대 폭을 720px 예외 없이 560px로 통일했습니다. 신청 화면(6단계)만 쓰던 720px 규칙을 제거했습니다.
- `.app-panel`에 `min-height: min(640px, calc(100dvh - 156px))`을 적용해, 콘텐츠가 짧은 화면도 공통 최소 높이를 확보하도록 했습니다. 콘텐츠가 이보다 길면 패널이 자연스럽게 늘어납니다.
- `.app-header`, `.question-progress`도 560px 기준선에 맞춰 헤더·진행 막대·패널의 좌우 경계를 통일했습니다.
- `.app-panel`과 `.notebook-page-content`를 세로 flex 컨테이너로 바꾸고, 하단 행동 영역(`intro-cta-section`, `question-actions-bar`, `contact-actions-bar`, `success-bottom-bar`)에 `margin-top: auto`를 적용해 콘텐츠가 짧을 때도 버튼이 패널 하단에 고정되도록 했습니다. `contact-form-sheet`도 flex 컨테이너로 바꿔 신청 3단계 각 화면에서 동일하게 동작합니다.
- 뷰포트 높이 640px 미만에서는 `.app-panel`의 최소 높이를 해제해 콘텐츠 잘림을 방지합니다.
- `npm test`(20개), `npm run lint`, `npm run build`를 통과했고, 데스크톱(1280×720)과 320×568 브라우저에서 인트로·질문·신청 1~3단계·오류 상태의 패널 폭(560px 고정)과 하단 정렬을 확인했습니다.
- 상세 기획은 [신청폼 중앙 패널 비율 일관화 기획](../04-디자인/신청폼-중앙-패널-비율-일관화-기획.md) 참고.

### 활력·피로 상황형 선택 및 기타 입력 구현

- 온도 페이지(02-A·02-B)의 시간대 버튼(새벽/아침/점심/저녁/밤/출퇴근길/매일 달라요)을 생활 상황 중심 선택지로 전면 교체했습니다. 앞 질문(하루 리듬)과 시간대를 반복해서 묻던 문제를 해결했습니다.
  - 02-A `어떤 순간에 가장 힘이 나나요?`: 푹 자고 일어난 뒤 / 혼자 집중할 때 / 사람들과 함께할 때 / 몸을 움직일 때 / 좋아하는 일을 할 때 / 할 일을 마친 뒤 / 날마다 달라요 / 기타
  - 02-B `어떤 순간에 가장 힘이 빠지나요?`: 잠이 부족할 때 / 할 일이 몰릴 때 / 오래 집중한 뒤 / 사람을 많이 만난 뒤 / 이동 시간이 길 때 / 쉬지 못할 때 / 날마다 달라요 / 기타
- 두 화면 모두 마지막에 `기타` 버튼을 추가했습니다. 선택하면 화면별 라벨(`힘이 나는/빠지는 다른 순간`)과 예시가 있는 입력란이 열리고 자동으로 포커스됩니다. 최대 50자, 공백만 입력하면 오류와 함께 입력란에 포커스가 돌아갑니다.
- 다른 버튼으로 바꿨다가 다시 `기타`를 선택하면 같은 방문 동안 작성했던 내용이 복원됩니다. `comfortableTimeOther`/`difficultTimeOther`를 `sessionStorage`에 함께 저장해 새로고침 후에도 선택과 입력값이 복원되도록 했습니다.
- 제출값은 준비된 버튼은 라벨 그대로, 기타 입력은 `기타: <내용>` 형식의 문자열로 기존 `comfortableTime`/`difficultTime` 필드에 담습니다. 두 초안 필드는 제출 payload에서 명시적으로 제외해 UI 전용 상태가 서버로 전송되지 않도록 했습니다. 스키마(`daylog-life-session-v3`), API·Apps Script·Google Sheets 계약은 변경하지 않았습니다.

- 당시 한 화면 배치를 목표로 조정했으나, 후속 검수에서 콘텐츠 높이가 viewport를 넘는 경우를 확인했습니다. 현재 기준은 가로 잘림과 입력 가림을 막고 자연스러운 세로 스크롤을 허용하는 것입니다.

### 질문 UI 가독성 개선

- 질문 화면을 중앙 단일 열로 바꾸고 답변 외의 보조 패널을 제거했습니다.
- 코치 메모 박스, 미선택 카드의 `+`, 생활 영역 영문 마커와 중복 종이 장식을 제거했습니다.
- 질문 단계 표기를 간단한 섹션명과 `현재 / 전체` 숫자로 정리했습니다.
- 모바일 선택 제목을 키우고 시간 레이블, 도움말, 오류와 우선순위 칩을 읽을 수 있는 크기로 높였습니다.
- 선택 카드는 단색 종이 면, Navy 테두리와 얇은 Yellow 선택선만 사용하도록 단순화했습니다.
- 다음 행동 문구를 `다음`, 마지막 질문은 `내 하루 요약 보기`로 짧게 바꿨습니다.

### 질문 화면 정렬 보완

- 데스크톱에서 로고, 진행선, 질문 제목, 선택 카드와 하단 버튼의 왼쪽·오른쪽 기준선을 통일했습니다.
- 진행선을 화면 끝에서 본문 폭 안으로 옮겨 질문 영역과 하나의 구성처럼 보이게 했습니다.
- 카드 안쪽 여백과 카드 사이 간격을 정리하고 보조 문장의 대비를 높였습니다.
- 모바일에서는 로고와 질문 본문의 왼쪽 기준선을 맞추고 선택 제목을 15px로 높였습니다.
- 320×568에서 일반 질문과 우선 영역이 펼쳐진 생활영역 질문이 한 화면에 유지되는 것을 다시 확인했습니다.

### 간편 신청 흐름 적용

- 첫 화면에서 `3분 기록 후 60분 오프라인 LIFE SESSION 신청` 목적을 바로 안내합니다.
- 시작 CTA를 `내 하루 적고 신청하기`로 변경하고 `5개의 짧은 선택 · 약 3분`을 함께 표시합니다.
- 긴 글을 쓰지 않아도 선택 답변이 자연스러운 노트 문장으로 자동 작성되게 했습니다.
- 희망 요일, 희망 시간대와 추가 이야기를 선택 입력으로 변경했습니다.
- 선택 입력을 `일정과 메모 추가하기` 안에 접어 기본 연락 신청 화면을 짧게 만들었습니다.
- 연락 신청의 필수값을 이름·호칭, 연락 방법, 연락처와 개인정보 동의로 제한했습니다.

### LIFE NOTE UI 보완

- 선택 카드의 강한 Yellow 면과 그림자를 줄이고 Navy 테두리, 체크와 얇은 Yellow 표시로 정리했습니다.
- LIFE NOTE 제목, 항목과 작성 문장의 글자 크기·대비를 높였습니다.
- 외곽 노트 줄과 제본 장식의 농도를 낮추고 실제 노트 영역에만 종이 표현을 집중했습니다.
- 1280×720 화면에서도 첫 CTA가 초기 화면 안에 들어오도록 세로 여백을 줄였습니다.
- 질문 화면에서는 작성 중인 노트를 표시하지 않고 전체 노트는 최종 요약에서만 표시합니다.

### 데이터와 접근성 보완

- 편안한 시간과 힘든 시간의 기본값을 제거하고 사용자가 직접 선택해야 다음 단계로 이동하게 했습니다.
- 시간 입력을 미선택 상태가 있는 접근 가능한 선택 목록으로 변경했습니다.
- 필수 선택 전 다음 CTA를 비활성화하고 선택·포커스 상태를 분리했습니다.
- 연락 입력 오류 시 첫 오류 입력으로 포커스를 이동하고 `aria-invalid`를 적용했습니다.
