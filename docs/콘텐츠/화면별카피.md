## 1. 확정 전에 필요한 운영 정보

아래 정보가 정해지기 전에는 연락 기한, 비용, 지역과 개인정보 문의 정보를 임의로 화면에 추가하지 않습니다. 사실과 무관하게 확정할 수 있는 문구는 먼저 반영합니다.

| 항목 | 현재 상태 | 필요한 결정 |
| --- | --- | --- |
| 최초 연락 기한 | 미정 | 신청일부터 언제까지 연락하는지 |
| 최초 연락 방법 | 전화 또는 문자 | 문자를 먼저 보내는지, 상황에 따라 달라지는지 |
| 나이 기준 | `현재 나이`로만 표시 | 만 나이인지 세는나이인지 |
| 진행 가능 지역 | 주변 역을 받아 조율 | 기본 지역과 불가능한 지역이 있는지 |
| 비용 | 화면에 없음 | 무료 체험인지, 비용이 있는지 |
| 개인정보 문의처 | 미제공 | 이메일 또는 전화번호 |
| 개인정보 처리방침 | 공개 URL 미제공 | 동의문과 함께 제공할 링크 |

문서 안의 `[운영 확정 필요]`는 실제 값이 정해진 뒤 교체합니다.

| 동의 없음 | 개인정보 수집·이용 내용을 확인하고 필수 동의에 체크해 주세요. |
| 요청 과다 | 신청 요청이 많아요. 10분 뒤 다시 시도해 주세요. |
| 연결 실패 | 신청 내용을 보내지 못했어요. 입력한 내용은 화면에 남아 있어요. 잠시 후 다시 신청해 주세요. |
| 설정 문제 | 지금은 신청할 수 없어요. 운영자가 신청 기능을 확인하고 있습니다. |

API의 필드 이름과 기술 상태를 그대로 보여주지 않습니다. 프론트에서 사용자가 고칠 수 있는 문구와 운영자가 확인할 문구를 분리합니다.
